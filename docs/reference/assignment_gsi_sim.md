# Assignment with Eric C. Anderson's gsi_sim

Run population assignment with
[gsi_sim](https://github.com/eriqande/gsi_sim), developed by assigner
co-author Eric C. Anderson. Eric also developed the original wrapper
used by assigner.

## Usage

``` r
assignment_gsi_sim(
  input = NULL,
  strata = NULL,
  select.markers = NULL,
  i = NULL,
  m = NULL,
  holdout = NULL,
  filename = NULL,
  i.folder = NULL,
  keep.gsi.files = FALSE,
  markers.sampling = "random",
  thl = 1
)
```
